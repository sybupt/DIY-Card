# 🃏 DIY Card - 三国杀卡牌制作器

基于 [Lyciumaker](https://github.com/CatScarf/Lyciumaker) 改造的在线卡牌制作工具，新增在线搜图功能。

👉 在线使用：[sybupt.github.io/diy-card](https://sybupt.github.io/diy-card/)

## ✨ 功能

- 🎨 制作标准三国杀卡牌（武将、体力、技能、插画）
- 🔍 在线搜图（Pexels 图库，点击即可载入卡牌）
- 💾 导出 PNG 图片
- 🧩 拼字模式

## 🚀 快速开始

### 在线使用

打开 [sybupt.github.io/diy-card](https://sybupt.github.io/diy-card/)

### 本地运行

git clone https://github.com/sybupt/diy-card.git
cd diy-card
npm install
npm run dev

## 🔑 在线搜图

首次使用需要 Pexels API Key：

1. 访问 [pexels.com/api](https://www.pexels.com/api/) 免费注册
2. 获取 API Key
3. 在搜图面板中粘贴即可
